# FEYNLAG_GAPS.md

Things `feynlag` (pinned commit in `pyproject.toml`) cannot do that a model in
this repository needed. Each entry names the model item that was **stopped**
(not worked around). Append-only; ids are referenced from `metadata.yaml →
feynlag_gaps`.

| id | model / item | what was attempted | what feynlag lacks | evidence |
|---|---|---|---|---|
| FG-1 | `sm_singlet_z2` / CP-even, CP-odd and charged scalar mass blocks | `Model.mass_matrix([h, S])` with `S = Scalar(real=True)` + `expand_vev({S: vS})` | `scalar_mass_matrix`/`charged_mass_matrix` shift the potential, differentiate, then call `Vacuum.at_vacuum`, which shifts **again**; for a real field the fluctuation symbol is the component itself, so every block is evaluated at `S = 2 v_S` (`M11 = 2λv² + 3λ_HS v_S²/2` instead of `2λv²`, `M22 = 11 λ_S v_S²` instead of `2 λ_S v_S²`; the would-be Goldstone blocks pick up `λ_HS v_S²` pieces). Tadpoles (single `at_vacuum`) and `physical_lagrangian` (single `shift`) are unaffected. | `models/sm_singlet_z2/tests/test_l0_l1.py::test_feynlag_mass_matrix_real_scalar_gap` (strict xfail: flips when fixed). Workaround kept *outside* feynlag: `feynlag_models.checks.scalar_mass_block` (public `build_mass_matrix` + one explicit vacuum evaluation). |
| FG-2 | `sm_singlet_z2` / L0 discrete invariance of the full Lagrangian | `Model(discrete_groups=[Z2]).check_invariance()` with `Z2.assign(1, S)` | `check_discrete_invariance` reports a violation on the `Dmu`-built Higgs kinetic term although `Z2` does not act on `H` at all (also fails with `H` explicitly assigned even; the residual is a momentum-tag artefact `p(Gp) − p(conjugate(Gp))`). Potential and Yukawa terms are checked correctly. feynlag's own `examples/thdm.py` never declares its `Z2` on the `Model`, so this path is untested upstream. | `models/sm_singlet_z2/tests/test_l0_l1.py::test_feynlag_discrete_kinetic_gap` (strict xfail). L0 is claimed on: gauge invariance + hermiticity + dimension of every term, anomalies, and `Z2` invariance of every non-`Dmu` term, with the kinetic false positive being the *only* failure (`only_failures`). |
| FG-3 | `seesaw_type1` / L3 UFO export | Export the heavy-neutrino vertices (`W ℓ N`, `Z ν N`, `h ν N`) obtained through `MajoranaRotation` | No UFO path for Majorana fermions: `write_ufo(fermion_vertices=…)` takes Dirac `bar`/`field` pairs and feynlag's `CLAUDE.md` lists "UFO export of Majorana vertices" as v2-deferred (fermion-flow conventions for self-conjugate fields are not implemented). The bosonic + charged-fermion part of the model could be exported, but that would not be *this* model's UFO. Item stopped; `maturity_level: 2`. | `models/seesaw_type1/model.py` (`extra["ufo"] = False`; `outputs()` writes no UFO). |
